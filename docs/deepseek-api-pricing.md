# DeepSeek API 报价速览（全家桶）

> - 抓取时间：2026-11-15（Asia/Shanghai）
> - 数据来源：DeepSeek 官方 API 文档「模型 & 价格」中文页 / English 页，以及 2026-11-13「DeepSeek 发布全家桶应用 API」公告。
> - 价格可能调整，实际以官方页面为准。

## 概要

DeepSeek 当前有两款主力模型：**deepseek-flash**（DeepSeek-V4.1-Flash-1017）和 **deepseek-v4-pro**（DeepSeek-V4-Pro-0813）。模型按 token 计费，并区分**高峰 / 空闲**时段，空闲价为高峰价的 5 折。

搜索、网页抓取、文件解析 / OCR、ASR、TTS 等全家桶能力在 token 费用之外，按次、按页、按小时或按字符**单独计费**。

## 1. 模型 Token 价格

### 1.1 人民币（官方中文页）

单位：**元 / 百万 tokens**。

| 模型 | 输入（缓存命中）空闲 | 输入（缓存命中）高峰 | 输入（缓存未命中）空闲 | 输入（缓存未命中）高峰 | 输出 空闲 | 输出 高峰 | 并发限制 |
|---|---:|---:|---:|---:|---:|---:|---:|
| deepseek-flash | 0.02 | 0.04 | 1 | 2 | 4 | 8 | 2500 |
| deepseek-v4-pro | 0.15 | 0.30 | 4.5 | 9.0 | 13.5 | 27.0 | 500 |

### 1.2 美元（官方英文页）

单位：**美元 / 百万 tokens**。

| 模型 | 输入（缓存命中）空闲 | 输入（缓存命中）高峰 | 输入（缓存未命中）空闲 | 输入（缓存未命中）高峰 | 输出 空闲 | 输出 高峰 |
|---|---:|---:|---:|---:|---:|---:|
| deepseek-flash | $0.003 | $0.006 | $0.15 | $0.30 | $0.60 | $1.20 |
| deepseek-v4-pro | $0.022 | $0.044 | $0.66 | $1.32 | $1.98 | $3.96 |

## 2. 峰谷时段

- **高峰时段**：北京时间周一至周五（不含中国法定节假日）**09:00–12:00、14:00–18:00**。
- **空闲时段**：其余所有时间，包括工作日 12:00–14:00、18:00–次日 09:00，以及周末和中国法定节假日全天。
- 空闲价 = 高峰价 × 50%。

英文页以 UTC 表述同一规则：周一至周五 01:00–04:00、06:00–10:00 UTC，不含中国法定节假日。

## 4. 全家桶工具价格

| 能力 | 计费单位 | 人民币 | 美元 |
|---|---|---:|---:|
| 联网搜索（文字 / 图片） | 每 1,000 次 | 5 元 | $0.75 |
| 网页抓取（Fetch） | 每 1,000 次 | 5 元 | $0.75 |
| 文件解析 / OCR | 每 1,000 页 | 1.5 元 | $0.225 |
| 语音合成（TTS） | 每 10,000 字符 | 3 元（限时 5 折：1.5 元） | $0.45（$0.225） |
| 语音识别（ASR） | 每小时音频 | 0.78 元（限时 5 折：0.39 元） | $0.116（$0.058） |

说明：

- 直接调用 Search / Fetch / OCR / ASR / TTS 接口，或让模型通过 `deepseek_web_search`、`deepseek_read_url` 等工具调用，均按上表价格计费。
- 通过对话 API 使用扩展能力时，**除工具调用费外仍照常收取 token 费**（官方公告明确）。
- 模型安全（内容风控）在官方定价页未单列价格；公告说明开启安全校验参数后提供基础风控。

## 5. 计费示例

### 5.1 纯模型调用

按「1M 输入（缓存未命中）+ 1M 输出」估算，不含缓存命中：

| 模型 | 高峰 | 空闲 |
|---|---:|---:|
| deepseek-flash | 2 + 8 = **10 元** | 1 + 4 = **5 元** |
| deepseek-v4-pro | 9 + 27 = **36 元** | 4.5 + 13.5 = **18 元** |

若 1M 输入全部缓存命中（输出仍为 1M）：

- **deepseek-flash**：高峰 0.04 + 8 = **8.04 元**；空闲 0.02 + 4 = **4.02 元**。
- **deepseek-v4-pro**：高峰 0.30 + 27 = **27.30 元**；空闲 0.15 + 13.5 = **13.65 元**。

### 5.2 带工具调用

1,000 次搜索 + 1,000 页 OCR + 1 小时 ASR（按刊例价）：

```text
5 + 1.5 + 0.78 = 7.28 元
```

另加模型对话本身的 token 费用。

## 6. 扣费规则

- 模型调用费用 = 各档 token 数量 × 对应单价；搜索、抓取、OCR、语音按调用量 × 单价。
- 费用从充值余额或赠送余额中扣减；两者同时存在时，优先扣减赠送余额。
- DeepSeek 保留调整价格的权利，建议定期查看官方定价页。
